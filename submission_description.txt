This Week 2 project demonstrates the practical implementation of supervised machine learning using Python and Scikit-learn. The project focuses on both regression and classification so that different types of prediction problems can be understood and evaluated within one workflow. A student performance dataset containing 120 records was used with features such as age, CGPA, attendance percentage, absences, study hours per day, and previous score. For the regression task, the objective is to predict the numerical Final Score. Linear Regression, Decision Tree Regressor, and Random Forest Regressor are trained and compared using Mean Absolute Error, Root Mean Squared Error, and R-squared. For the classification task, the objective is to predict whether a student belongs to the Pass or Needs Support category. Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors are implemented and evaluated using Accuracy, Precision, Recall, and F1-score. The dataset is divided into training and testing portions so that the final measurements are obtained on unseen data. Standard scaling is applied through Scikit-learn pipelines for models where feature magnitude can affect the result. The project includes the complete Python implementation, dataset, result files, requirements file, README documentation, and a detailed report. The model comparison shows how different algorithms behave on the same supervised learning problem and why multiple evaluation metrics are useful when selecting a model. The work is software and technically related because it requires executable Python code, machine learning libraries, data handling, model training, prediction, and evaluation. The project is organized so it can be placed in a public GitHub repository and reproduced by installing the listed dependencies and running the training script.
